## 核心架构判断

> **自然语言操控电脑 + 本地文档自动化 + 智能代理** 需求真实且切中用户痛点。
> Pi-a 采用 **Deno Desktop（In-process 嵌入，零 IPC 开销）+ Pi Agent 引擎 + 本地开源文档栈** 的选型，核心优势在于：
> 1. **架构极简**：内存直接绑定与极简事件流，拒绝臃肿层级。
> 2. **模型自由**：原生覆盖 DeepSeek、Kimi/Moonshot、MiniMax、智谱等多主流模型，不锁死单一厂商。
> 3. **本地优先与开源轻量**：核心能力本地自治、隐私优先，拥有极高的启动与响应速度。

## 技术选型概览

| 层级 | 选型 | 理由与优势 |
|---|------|---|
| **桌面框架** | **Deno Desktop** | In-process bindings（零 IPC 往返）、轻量包体、单机编译 |
| **Agent 内核** | **Pi Agent Engine** (`pi-agent-core` + `pi-ai`) | 极简架构、中文大模型覆盖全面、原生钩子拦截 |
| **文档处理引擎** | **开源文档栈** (`docx` / `exceljs` / `pptxgenjs` / `pdfjs-dist`) | 本地解析与生成，无需依赖外部付费 API |
| **OS 自动化** | **Deno Native API + Terminal Subprocess** | 安全执行 Shell 指令与操作系统级能力编排 |
| **前端框架** | **React + TypeScript + Custom CSS Tokens** | 蔚蓝现代设计系统、高保真微交互、完全灵活定制 |
