## 三处修复：任务折叠 / 会话可删 / 开始对话不预选空间

1. **任务 section 不能折叠**：原 `SectionHeader` 内部有 `open` 状态，但列表渲染未受 `open` 控制（始终显示），点标题只转箭头。改为 `CollapsibleSection`，用 `open` 控制 `<div className="section-body">` 显隐。任务/空间两个 section 现在都能折叠。
2. **任务会话删不掉（UI 层）**：任务列表的 `ConvItem` 被传 `isHover={false}` + `onHover={() => {}}` 空函数，hover 永不触发，删除按钮只在「当前会话」时显示 → 非当前会话点不到删除。改为 `ConvItem` 自管理 `hovered`/`menuOpen`（`useState`），并对 `currentConvId` 用 `useStore` 选择器订阅，任意会话 hover 即出删除/更多；「移动到空间」菜单对任务会话也可用。
3. **开始对话时空间按钮还选着**：`createConversation` 新建后复位 `composerWorkspaceId = null`，下一次「开始对话」默认不归属任何空间（任务）。
4. **「Test Edit」会话删不掉的真正根因（后端）**：`DELETE /api/conv/:id` 返回 500 `FOREIGN KEY constraint failed`。`artifacts` 表有 `artifacts.conversation_id → conversations.id`（on_delete=NO ACTION），而 `deleteConversation` 只删了 `messages` 没删 `artifacts`。已补 `DELETE FROM artifacts WHERE conversation_id = ?`。修复后两个 Test Edit 会话删除返回 200。
